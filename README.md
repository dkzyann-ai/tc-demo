# テスト作成ツール

学校・塾の教員が数学I・Aの問題を管理し、テストを作成・印刷できるツールです。

現在は、Windowsでローカル実行できるDEMOを作成し、将来は組織内共有・認証・権限管理を備えたWebアプリへ発展させる方針です。

## 方針

- 主言語：TypeScript
- DEMO：Reactの画面をWindows向けデスクトップアプリとして配布し、ローカルにデータを保存する。
- 本番：ReactのWeb画面、Node.jsのバックエンドAPI、PostgreSQLで構成する。

詳細は [技術方針と将来拡張](docs/ナレッジ/技術方針と将来拡張.md) を参照してください。

## ディレクトリ

- `src/`：アプリケーションの実装
- `tests/`：自動テスト
- `docs/`：設計資料とナレッジ
- `scripts/`：開発・検証・配布の補助スクリプト
- `assets/`：アイコン、同梱画像、初期データなどの配布資材
