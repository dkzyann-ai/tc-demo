# テスト作成ツール DEMO ご利用手順

## 1. はじめに

このアプリは、問題を登録し、小テストまたは定期テストを作成・印刷するためのWindows用アプリです。
インターネット、Node.js、WSL、Docker、クラウドアカウントは必要ありません。

## 2. 起動方法

1. 配布されたZIPファイルを右クリックし、**すべて展開**を選びます。
2. 展開したフォルダを開きます。
3. **テスト作成ツール DEMO.exe** をダブルクリックします。

初回起動時にWindowsの保護メッセージが表示された場合は、配布元を確認したうえで「詳細情報」から実行してください。

## 3. 問題を登録する

1. 画面上部の「問題作成」を開き、問題名・科目・単元・配点を入力します。
2. 問題文と正答を入力し、「問題を保存」を押します。
3. 必要に応じて問題用の画像を選択します。画像は問題用紙に表示されます。
4. 同じ画面の登録済み問題から「編集」または「削除」を選べます。

問題とテストは、このPC内に保存されます。

## 4. テストを作成する

1. 「テスト作成」でテスト種別と科目を選び、テスト名を入力します。
2. 問題一覧の問題をクリックして、テストに入れます。
3. テストに入れる問題で、配点と上下ボタンにより順序を調整します。
4. 「保存」を押します。
5. 「テスト履歴」の「再編集」で、後から内容を変更できます。履歴画面ではキーワード検索と削除もできます。

## 5. 印刷する

1. 保存済みテストを「再編集」で開きます。
2. 画面下部の「問題用紙」または「答え」を選びます。
3. 「印刷」を押して、Windowsの印刷画面からプリンターと部数を指定します。

印刷はA4縦向きを前提にしています。

## 6. 注意

- 問題を削除すると元には戻せません。
- 保存済みテストで使用している問題は、先にテストから外すまで削除できません。
- 他のPCへデータを移す機能、共有、ログインはこのDEMOには含まれません。
