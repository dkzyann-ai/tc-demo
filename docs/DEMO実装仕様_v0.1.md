# テスト作成ツール DEMO 実装仕様 v0.1

## 1. この文書の位置付け

この文書は、Windows向けローカル単体アプリとして配布するDEMOの実装範囲と受け入れ条件を定める。
チャットで合意した最新要件を正とし、`docs/04_設計/v0.1/` の既存資料は画面構成の参考にとどめる。

## 2. 対象としない機能

- 共有、組織・利用者管理、ログインなどの正式認証
- 関数グラフ作成
- クラウド同期、オンライン接続

初回起動時はログイン画面を表示せず、ホーム画面を開く。問題とテストは、そのPCの利用者だけが扱うローカルデータとする。

## 3. 採用する画面

1. **テスト作成**：小テストまたは定期テスト、科目、テスト名を設定し、登録問題をクリックして選択する。問題用紙または答えをA4で印刷できる。
2. **テスト履歴**：保存済みテストを検索し、再編集または削除する。
3. **問題作成**：問題名、科目、単元、配点、問題文、答え、解説、任意の問題画像を登録・編集・削除・検索する。保存した問題はテスト作成画面へ自動で追加する。

## 4. データ

### 問題

|項目|内容|
|---|---|
|id|内部識別子|
|title|問題一覧で判別する名前|
|subject|選択した数学科目|
|unit|単元名|
|questionText|問題文|
|answerText|正答|
|explanation|解説（任意）|
|defaultPoints|標準配点|
|imageData|問題用紙に差し込む任意画像|
|createdAt / updatedAt|作成・更新日時|

### テスト

|項目|内容|
|---|---|
|id|内部識別子|
|name|テスト名|
|kind|`小テスト` または `定期テスト`|
|subject|選択した数学科目|
|items|問題ID、テスト内の配点、表示順の組|
|createdAt / updatedAt|作成・更新日時|

テストは問題を参照する。参照中の問題を削除しようとした場合は、影響するテスト名を示して確認を求める。

## 5. ローカル保存とElectronの責務

- Electronのアプリ用データフォルダにSQLiteデータベースとして保存する。PCごとに独立したデータであり、クラウドへ送信しない。
- 画面側は直接ファイルへ触れず、preload経由の最小APIだけを使う。
- Electronのmainプロセスが保存・読込・印刷を担当する。
- `nodeIntegration: false` と `contextIsolation: true` を維持する。
- 保存処理は `src/storage/` のリポジトリ境界に集約し、将来はAPI・DB実装に交換できるようにする。

## 6. 印刷

- 用紙はA4縦向きとする。
- 問題用紙にはテスト名、氏名記入欄、問題番号、問題文、任意画像、配点を出力する。
- 答えにはテスト名、問題番号、正答、配点を出力する。
- 2種類のプレビューは同じテスト内容から生成し、個別に印刷できる。

## 7. 受け入れ条件

1. 問題を登録し、アプリを再起動しても一覧に残る。
2. 問題を編集・削除できる。削除前には確認が表示される。
3. 複数問題を選び、テスト内の順序と配点を変更でき、合計点が即時に変わる。
4. 保存したテストを再度開き、編集して再保存できる。
5. 問題用紙・答えがA4プレビューに正しく表示され、印刷ダイアログを開ける。
6. Windows配布版をZIP展開後に起動でき、利用者側でNode.js、WSL、Docker、クラウドアカウントを必要としない。
