ER図・テーブル設計（たたき台）

DEMOスコープ（認証は簡易ログインのみ／組織共有なし）に絞った最小構成、5テーブルです。

ER図（概略）

teachers（教員）
idPK
nameVARCHAR
created_atTIMESTAMP
units（単元マスタ）
idPK
subjectVARCHAR
nameVARCHAR
sort_orderINT
teachers 1 → N problems　　units 1 → N problems
problems（オリジナル問題）
idPK
teacher_idFK
unit_idFK
titleVARCHAR
difficultyVARCHAR
default_pointsINT
answer_typeVARCHAR
bodyTEXT
answerTEXT
explanationTEXT
graph_formulaVARCHAR(任意)
image_urlVARCHAR(任意)
problems N ← → N tests（test_problemsで中継）
tests（小テスト）
idPK
teacher_idFK
titleVARCHAR
column_layoutINT(1/2)
paper_sizeVARCHAR
row_height_mmINT
show_answer_blankBOOLEAN
test_problems（中間）
idPK
test_idFK
problem_idFK
order_noINT
points_overrideINT(任意)

テーブル定義

teachers — 簡易ログインの名前を保存。作成者の判定に使用
カラム型説明
idSERIAL / UUID主キー
nameVARCHAR(100)教員名（ログイン時に入力）
created_atTIMESTAMP初回ログイン日時
units — 単元マスタ。数学Ⅰ・Aの8単元を初期データとして投入
カラム型説明
idSERIAL主キー
subjectVARCHAR(20)「数学Ⅰ」「数学A」。将来の他科目追加もここに追加するだけでOK
nameVARCHAR(50)「数と式」「2次関数」など
sort_orderINT表示順
problems — オリジナル問題。DBシートのtest_probをここに統合・拡張
カラム型説明
idSERIAL / UUID主キー
teacher_idINT (FK)作成者
unit_idINT (FK)単元
titleVARCHAR(200)問題タイトル
difficultyVARCHAR(20)基礎／標準／応用
default_pointsINTデフォルト配点（テスト内で上書き可）
answer_typeVARCHAR(20)記述／選択／数値
bodyTEXT問題文
answerTEXT正答
explanationTEXT解説
graph_formulaVARCHAR(200)　NULL可関数グラフ（オプション機能）
image_urlVARCHAR(500)　NULL可添付画像（オプション機能）
created_at / updated_atTIMESTAMP作成・更新日時
tests — 小テストの見出し情報（テスト作成／解答用紙／答えは同じデータをタブで出し分け）
カラム型説明
idSERIAL / UUID主キー
teacher_idINT (FK)作成者
titleVARCHAR(200)テスト名
column_layoutINT段組み（1 or 2）
paper_sizeVARCHAR(10)用紙サイズ（A4等）
row_height_mmINT解答欄の高さ
show_answer_blankBOOLEAN解答欄ありなし
test_problems — テストと問題の中間テーブル（多対多＋並び順・配点上書き）
カラム型説明
idSERIAL主キー
test_idINT (FK)紐づくテスト
problem_idINT (FK)紐づく問題
order_noINT表示順（大問1,2,3…）
points_overrideINT　NULL可このテストだけの配点（未指定ならproblemsのdefault_pointsを使用）
DEMOでは意図的に含めていないもの
・組織／学校・塾テーブル（共有機能はDEMO対象外の仮決定のため）
・認証テーブル（パスワード等）（簡易ログインのみのため、teachers.nameで代用）
→ どちらも3章の本番決定事項が固まった段階で追加します。unitsのsubjectカラムは他科目拡張にそのまま対応できる設計にしてあります。
※ 型（VARCHAR(200)など）は目安です。詳細設計の段階で実データに合わせて調整します。
